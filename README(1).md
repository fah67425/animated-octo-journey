# Personal Website

A simple personal website built with HTML and CSS. It presents personal
information and contact details in a clean, easy-to-navigate layout.

## Features

-   Personal information section
-   Contact information section
-   Instagram/social profile information
-   Simple responsive website structure
-   Easy to deploy with GitHub Pages

## Built With

-   HTML5
-   CSS3

## Project Structure

``` text
website/
├── index.html
├── style.css
└── README.md
```

## Running Locally

1.  Open the project folder in VS Code.
2.  Open `index.html` in your browser.
3.  Edit the HTML or CSS files to customize the website.

## Deployment

This project can be deployed for free using GitHub Pages.

1.  Push the project to a GitHub repository.
2.  Open the repository on GitHub.
3.  Go to `Settings` → `Pages`.
4.  Under `Build and deployment`, select `Deploy from a branch`.
5.  Select the `main` branch.
6.  Select `/ (root)` as the folder.
7.  Click `Save`.
8.  Wait for GitHub Pages to publish the site.

## Customization

You can customize:

-   Text and personal information in `index.html`
-   Colors, spacing, fonts, and layout in `style.css`
-   Additional sections, images, and links
